# PCM / WAV 多通道播放器与分析工具

macOS 原生桌面应用（Python + PySide6 + PortAudio），面向音频/嵌入式调试场景：打开裸 PCM 与
WAV，多通道显示与播放，时域波形 + 谱图联动，时间/幅值独立缩放，滚轮滑窗、点击定位。

## 快速开始

```bash
cd pcmAnalysis
./run.sh                       # 首次会自动建 venv 并装依赖（走清华镜像）
./run.sh samples/mic8_48k_24bit.wav      # 直接带文件启动
./make_app.sh && open PCMAnalyzer.app    # 生成可双击的 .app
```

依赖：`numpy`、`soundfile`、`sounddevice`、`PySide6`。Python ≥ 3.10（实测 3.12.14）。

## 功能对照

| 需求 | 实现 |
| --- | --- |
| PCM/WAV 打开播放，支持多通道 | `AudioBuffer` 统一解码：8/16/24/32bit 整型（有/无符号、大小端）、32/64bit 浮点、交织与平面排布、文件头偏移；播放走 `sounddevice.OutputStream` 多通道 |
| 显示打开的文件；多文件合并通道 / 单文件解交织 | 左栏树：每个文件展开即**解交织**后的单声道列表（勾选控制显示与播放）；⌘/Shift 多选文件 →「合并所选文件通道」生成一个真正的多声道源，可整体播放、可导出为一个多声道 WAV；「解交织导出」把每个通道写成独立单声道 WAV |
| 时域 + 频域波形、播放进度 | 上：时域（分道/叠加、包络/RMS/样本折线、线性/dBFS 纵轴）；下：谱图（STFT 时频热力图，线性/对数频率、4 种色标、可调 dB 底）；播放指针贯穿两图，传输条有进度条 + 时间/帧读数 |
| 时间维度放大、幅值放大 | 两套独立缩放：`⌘/Ctrl+滚轮` 或「时间+/−」改时间窗；`⌥/Shift+滚轮` 或「幅值+/−」改幅值量程（1× = ±1.0，4096× 上限）。顶部另有一条**全曲缩略图**，按通道分道画整段包络并用亮框标出当前时间窗 |
| 滚轮滑时间窗、点击定位播放 | 无修饰滚轮 = 横向滑动时间窗（触控板双指按像素位移连续滚动）；单击波形/谱图 = 定位播放；按住拖动 = 框选时间选区；中键拖动 = 平移；双击 = 适配全曲 |

## 顶部全曲缩略图

时间轴放大后，光看主图容易失去全局位置感。顶部横条按通道分道画出**整段音频的包络**
（配色与主图一致、分道布局与主图同源），并用亮框标出当前时间窗，框外轻微压暗；
标题行实时显示「全曲时长 · 窗口宽度 @ 起点 (起止百分比)」。

| 操作 | 效果 |
| --- | --- |
| 拖框体 | 平移时间窗（宽度不变） |
| 拖框体左/右边 | 改窗口宽度 = 时间缩放，另一端固定 |
| 点框外空白 | 窗口中心跳到点击处 |
| 滚轮 / `⌘+滚轮` / `⌥+滚轮` | 与主图同一套约定：滑窗 / 时间缩放 / 幅值缩放 |
| 双击 | 适配全曲 |

窗口框窄到 12px 以内时（放大很多），整框一律按「可平移」判定，避免左右边缘吸附互相
抢占导致框拖不动；此时改宽度用 `⌘+滚轮`，标题行也会提示这一点。全曲包络在后台线程分块
读盘计算（每块 ≤262144 样本/通道），主线程只重绘窗口框与播放指针。实测 46MB / 8 通道 / 60s
的素材全曲包络渲染 **0.06s**（页缓存已热的情况下），之后仅在通道集合、总时长或控件尺寸变化时
重算，缩放/平移期间完全不重算。

## 裸 PCM 参数

裸 PCM 不含任何元信息，打开时弹窗指定：采样率、通道数、样本格式（uint8/int8/int16/int24/int32/
float32/float64）、字节序、跳过文件头字节数、是否平面排布。弹窗实时显示「解析出的帧数 / 时长 /
每帧字节数」，若文件长度不是 `通道数×位深` 的整数倍会橙色告警——这是参数填错最常见的信号。

参数自动记入「最近」（去重、置顶），也可「存为预设」。配置落在
`~/Library/Application Support/PCMAnalyzer/config.json`。

## 多通道与时间轴约定

所有源在**帧 0 对齐**，共享一条全局时间轴；工程采样率可在传输条上切换，采样率不同的源按
`i × rate_src / rate_out` 线性换算后混合播放与显示（长度不足的源补零）。因此「48kHz 立体声 +
16kHz 单声道」可以叠在同一时间轴上比对，也能合并导出成一个 3 通道文件。

## 实测数据

| 项目 | 结果 |
| --- | --- |
| 46MB / 8 通道 / 60s 裸 PCM | 打开 + 全曲渲染 1.21s；连续 40 次放大到 0.757ms 窗口，渲染 0.65s |
| 播放实时性 | 1.51s 墙钟推进 1.49s 音频（Δ71,680 帧），35 次回调、块长 2048、空回调 0、underrun 0 |
| 输出延迟 | 48.7ms（PortAudio `stream.latency`，Mac mini 内置扬声器） |
| 谱图幅度校准 | 整周期 -3dBFS 正弦读出 -3.00dB；半格偏离时 1.10dB 扇贝损失（Blackman 窗标称值） |
| 解码精度 | 7 种位深/字节序/排布往返最大相对误差 < 2e-3（即 1 LSB） |

## 验证方式

```bash
.venv/bin/python -m tests.selftest          # 22 项无头自检，全绿退出码 0
QT_QPA_PLATFORM=offscreen .venv/bin/python tools/gui_probe.py   # 19 步离屏渲染 + 交互 + 播放
.venv/bin/python tools/make_samples.py      # 重新生成 12 个验收素材 + manifest.json
```

`tests/selftest.py` 覆盖：PCM 各位深解码与真值比对、交织/平面、文件头偏移、越界补零、按像素
抽稀正确性、谱图幅度/频率校准、长窗口自动抬升 nfft（瞬态可检出）、跨采样率时间轴对齐、统计量、
色标、合并通道与导出回读、解交织导出、移除源后合并源级联收缩、裸 PCM 导出往返、视图坐标数学
（像素↔帧往返、缩放锚点零漂移、边界钳制、信号去重）、播放环形缓冲消费顺序与跳转/循环折返、
配置持久化、顶部缩略图的命中区判定（窄框必须可平移）与分道布局（不重叠、不越界、主图同源）。

`tools/gui_probe.py` 真实构建主窗口跑 19 步（含起播、缩放、合并、谱图切通道/换 FFT/对数频率、
选区循环、5 种 PCM 格式混开、缩略图拖框平移/拖边改宽/点击跳转/滚轮锚点缩放/双击适配），断言播放
速度不偏离实时 >12%、谱图确实算出能量（防「整张图静默全黑」这类不报错的错），截图输出到 `probe/`。

## 已知限制

- **输出通道数受声卡限制**：内置扬声器只有 2 通道，勾选 >2 通道时状态栏会提示「按前 2 个通道播放」。
  要真多通道输出需接 USB 音频接口并在传输条里选对设备。
- **跨采样率混合用线性插值**，分析足够，但不是带限重采样；对音质敏感的混播请先离线重采样。
- **24bit 只支持 3 字节 packed**（含大端），不支持 WAV 里 32bit-in-24 的容器格式（soundfile 会自己处理，
  所以 WAV 路径不受影响）。
- **谱图按当前时间窗重算**（90ms 防抖），极长窗口 + 极大 FFT 时会有短暂「计算中」。
- 没有：频谱切片/传递函数、标记点、时间拉伸、导出图像文件（右键可复制当前视图到剪贴板）。
